# Before you finish: is the tuckit board current?

A stale board makes the SSOT lie. Reconcile now.

1. **Did this session decide to do something NEXT or LATER? Put it on the board
   — this matters most.** A committed next step (e.g. "backend this slice,
   frontend NEXT slice") → create a planned Slice now in the right Area (leave
   its spec empty; tuckit will show it as "needs design") so it shows up as
   what's next. A vaguer follow-up or "someday" → capture a Ticket in the Inbox.
   An agreement that isn't in tuckit does not exist — the chat log is not the
   SSOT.
2. New follow-ups or bugs that surfaced this session → capture as Tickets.
3. What you actually did → check off completed Bites and leave a note on the
   Slice (what you did, blockers, PR links).
4. If a Slice is genuinely finished → advance its stage (e.g. ready to ship /
   shipped).
5. If there is nothing to reflect, do nothing — this is a reminder, not a gate.
